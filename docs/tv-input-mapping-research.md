# 遥控器方向键映射方案

2026-10-25，基于当前固定版本源码和用户提供的手柄映射项目。

## 现状

方向键并非未使用。当前 `handleXComponentKey` 通过 `dispatchPhysicalKeyForSession` 将上、下、左、右（2012–2015）转发为电脑方向键。确认键 2016 留给电视点击处理，返回键先关闭面板，再退出远程页。触控区轻扫走触摸转滚轮逻辑，不能与物理方向键合并判断。

参考项目的 `Mapping(button, gesture, action)` 和 `Profile` 模型可借鉴；其 macOS CGEvent、NSWorkspace、快捷指令执行器不能直接搬进电视应用。

## 建议首版

在每台电脑的设置中增加按键映射，默认保持现有方向键行为。允许映射为电脑按键或组合键、滚轮、平移画布、切换显示器。组合键按目标平台区分 Command 与 Control，不根据电视系统猜测。

实施前先记录遥控器 `deviceId` 与按下、松开事件，确认不会把蓝牙键盘的方向键一起改掉。设置面板和输入框持有焦点时，映射让位于本地界面；后台、断连和面板开启时释放所有已按下的远端按键。长按重复需分别定义为重复动作或持续按住，不能缺失 key-up。

启动电脑程序、打开 URL 等动作需要受认证的电脑助手执行，并限制允许的动作；RustDesk 的按键通道不是任意命令执行接口。

## 状态

首版已实现，详见下方实现与验证边界。实际设备是否提供可靠 `uniq` 仍需实机确认；未确认时按仅本次连接处理。

## 首版实现（2026-10-25）

设置面板增加“遥控器方向键 · 当前电脑”，四个实体方向键可分别选择电脑按键、复制/粘贴/全选/撤销、滚轮、画面平移或下一块显示器。默认仍为原方向键，触控轻扫和停留拖动逻辑不变。

用户先点“绑定遥控器”，按一个实体方向键，再确认系统识别出的设备。只绑定该 `deviceId`，其他键盘不改映射。存在可靠且唯一的 `uniq` 时，使用设备名称、厂家、型号和 `uniq` 保存指纹，下次解析当前设备列表；无法唯一识别时不自动绑定。没有可靠 `uniq` 的设备明确显示“仅本次连接”，数字 ID 不写入持久化配置。设备变化立即取消绑定并重新解析；动作配置按账户和电脑保存。

映射动作使用完整的按下/松开序列；方向键、滚轮、平移、翻页最多每 80 毫秒重复一次，快捷键与切屏每次按住只执行一次。设置、听写、IME、失焦、后台、切屏和权限阻塞时不发往电脑，已取消的长按必须先松开才能再次执行。组合键使用已经确认的远端键盘布局。

验证：实际策略与接入方法的 Node 测试、严格 TypeScript 静态检查、固定上游补丁应用验证已通过。完整 HarmonyOS 构建、安装和遥控器实机绑定/重复键行为由集成验收确认；此记录不表示已实机验证。

## 按键与手势扩展（2026-10-25）

参考小米控制器项目的“按键 → 手势 → 动作”模型，独立实现电视 KeyEvent 状态机，没有移植 macOS 的 HID/ATVV 采集或 CGEvent 执行器。设置中先选择上、下、左、右、菜单键或语音键，再分别配置单击、双击、长按。动作包括电脑按键、滚轮、平移、切屏，以及电视本地的打开设置、文字与听写、完整画面/短边铺满切换；“恢复本键默认”撤销该键的手势映射。

- 默认原按键不进入延时识别，继续使用上游原始 Down/Up。只配置单击动作时立即执行，导航类按系统 repeat 最快每 80 毫秒执行一次。
- 显式配置双击后，首击松开等待 280 毫秒；第二次按下落在窗口内时，松开只执行双击。第二击若继续保持且配置了长按，则只执行长按。
- 显式配置长按后，达到 650 毫秒执行一次；短按在松开时执行单击（只有配置双击才继续等双击窗口）。长按、双击和单击互斥，不把系统 repeat 当作新的一击。
- 手势动作均发送完整按下/松开，长按映射也不留下持续按住的电脑按键。设置、听写、IME、失焦、后台、设备变化、断连及映射修改撤销待执行动作和定时器。未映射或其他键盘事件只交给上游输入所有者一次，避免吞掉 KeyUp。
- 配置升级为版本 2，自动迁移原四方向动作；新增的菜单、语音和手势默认不启用。仍按当前账户与电脑保存，不改变已有触控轻扫/拖动。

菜单候选为 SDK 的 MENU 2067，需电视实际分发才可使用。语音键没有预置绑定；“检测语音键”必须在已绑定遥控器上收到同一 ASSISTANT 2722 或 SEARCH 9 的完整 Down/Up 才开放配置。主页、返回、电源、音量及任意电脑键不能学习为语音键。未收到完整事件会显示可能由系统接管；这不承诺抢占小艺，也不读取麦克风。系统键盘显隐仍影响系统语音行为。详见 [系统按键边界](tv-system-key-boundaries.md)。

扩展验证包括真实策略的时间边界、重复事件、单双长按互斥、设备和焦点撤销、真实输入所有者的完整 Down/Up 链、绑定设备的语音学习，以及已取消定时回调的 generation 防护。32 项映射测试与 36 项现有电视运行逻辑测试通过，策略严格类型检查和固定上游的失焦/释放取消钩子检查通过。完整 HarmonyOS 构建和菜单/语音实机事件由集成验收确认。
