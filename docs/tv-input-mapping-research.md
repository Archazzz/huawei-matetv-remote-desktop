# 遥控器方向键映射方案

2026-10-25，基于当前固定版本源码和用户提供的手柄映射项目。

## 现状

方向键并非未使用。当前 `handleXComponentKey` 通过 `dispatchPhysicalKeyForSession` 将上、下、左、右（2012–2015）转发为电脑方向键。确认键 2016 留给电视点击处理，返回键先关闭面板，再退出远程页。触控区轻扫走触摸转滚轮逻辑，不能与物理方向键合并判断。

参考项目的 `Mapping(button, gesture, action)` 和 `Profile` 模型可借鉴；其 macOS CGEvent、NSWorkspace、快捷指令执行器不能直接搬进电视应用。

## 建议首版

在每台电脑的设置中增加按键映射，默认保持现有方向键行为。允许映射为电脑按键或组合键、滚轮、平移画布、切换显示器。组合键按目标平台区分 Command 与 Control，不根据电视系统猜测。

实施前先记录遥控器 `deviceId` 与按下、松开事件，确认不会把蓝牙键盘的方向键一起改掉。设置面板和输入框持有焦点时，映射让位于本地界面；后台、断连和面板开启时释放所有已按下的远端按键。长按重复需分别定义为重复动作或持续按住，不能缺失 key-up。

启动电脑程序、打开 URL 等动作需要受认证的电脑助手执行，并限制允许的动作；RustDesk 的按键通道不是任意命令执行接口。
