## 已核对但本轮未改

- 通知请求带有前后台/代数检查；退出前台销毁轮询请求，迟到回包不得写入收件箱。推送单次请求在 `finally` 销毁，点击仍需经过配对、作用域、过期时间和电脑映射校验。现有相关测试通过，没有为“整理”改动这些边界。
- 会话恢复继续等待原生断连终态与注册表释放，未通过 UI 超时强行释放槽位；旧页面释放画布后撤销对进程画布的操作权。保留现有分层，未合并生命周期方法。此项是代码检查，长时间前后台压力表现仍以实机为准。
- `TvAudioProbe` 的播放拥有者负责 stop/release，取消使正在等待的播放失效；输入测试页隐藏/销毁会取消测试。没有新增播放或录音行为。
- 生成器以 overlay/fragments 为源码入口，多数固定上游补丁使用唯一锚点校验；生成目录用合并复制保留本地工程与签名。删除或重命名 overlay 文件后，旧生成文件可能仍留在 `.work`，后续可采用生成文件清单精确回收。本轮不改成清空目录，避免删除签名、本地配置及用户文件，也不声称合并复制等价于全新构建。
- Python 服务的正常退出仍使用现有 daemon 请求线程/推送线程模型。不能直接在 `server_close` 尾部关闭共享 SQLite，因为活跃线程可能仍使用它。若需要在同一 Python 进程里反复启动/关闭，应另加停止接单、排空工作线程、最后关闭持久化的完整生命周期；本轮只修没有活跃请求的启动失败路径。
- 配色字面量仍存在于未纳入本次设置页整理的首页与通知页；没有进行全仓外观替换。设置 token 的扩展由主 agent 统一，避免多个模块同时改动视觉契约。
