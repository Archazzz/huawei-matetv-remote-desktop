# 电脑端与网络配置

## 局域网电脑

在每台需要被控制的电脑上，从 [RustDesk 官方网站](https://rustdesk.com/) 安装适用于该系统的 RustDesk。

1. 在 RustDesk 的安全设置中开启 **直接 IP 访问**；默认 TCP 端口为 `21118`，以安装版本显示的设置为准。
2. 设置仅自己知道的固定访问密码。首次连接正常认证并保存密码后，点电视电脑卡片会直接认证连接；密码失效仍需重新输入。不要把密码写进桥接配置或提交到 Git。
3. macOS 需要在系统设置中为 RustDesk 授予屏幕录制、辅助功能等应用提示的权限。完成授权后，必要时重启 RustDesk。
4. Windows 允许 RustDesk 通过受信任的家庭网络防火墙；需要登录界面控制或无人值守时，按官方说明安装服务。UAC、安全桌面和锁屏能力需要单独测试。
5. 在电视端“添加电脑”填名称、电脑的局域网 IP 和实际直接访问端口。优先在路由器中为设备保留地址。

先用另一台电脑的 RustDesk 验证直接 IP 连接，能把电脑权限和网络问题与电视适配问题区分开。

## 外网电脑与 Tailscale

Tailscale 负责组网，本身不采集屏幕或控制鼠标。方案需要一台和电视同处家庭网络、保持在线的 Mac 或 Linux/NAS 作为桥接设备。

1. 在桥接设备及外网电脑上登录自己的 Tailscale 网络。
2. 外网电脑安装并配置 RustDesk，开启直接 IP 访问。
3. 从桥接设备确认可达外网电脑的 Tailscale IP/域名和 TCP `21118`。tailnet 访问规则及外网电脑防火墙需要允许这条特定连接。
4. 在桥接设备上运行本项目 `bridge.server`。电视连接的是桥接设备的家庭网络地址及监听端口。

示例（以下为示意地址，必须替换）：

```json
{
  "forwards": [
    {
      "name": "travel-laptop",
      "listen_host": "192.168.50.10",
      "listen_port": 21119,
      "target_host": "100.64.0.10",
      "target_port": 21118,
      "allowed_clients": ["192.168.50.20/32"],
      "max_connections": 4,
      "idle_seconds": 300,
      "connect_timeout": 10
    }
  ]
}
```

- `listen_host`：家中桥接设备的 LAN 地址。
- `allowed_clients`：电视的固定 LAN 地址，建议单个 `/32`；不是远端电脑地址。
- `target_host`：外网电脑的 Tailscale 地址。
- 电视填写 `192.168.50.10` 和 `21119`，密码仍是外网电脑的 RustDesk 密码。

不需要把家庭路由器端口映射到公网。桥接没有额外的用户认证，信任边界依赖 LAN 白名单、系统防火墙、Tailscale 访问规则及 RustDesk 自身认证。IP 白名单不等价于用户身份验证。

桥接原样传输协议字节，不改变上游的认证、密钥交换和加密设置。请按 RustDesk 的提示验证加密/密钥状态，不能因为启用了 Tailscale 就推断电视到桥接的 LAN 链路也由 Tailscale 加密。

## 多网卡与跨网段

通过桥接连接 Windows 时，Windows 收到的是桥接电脑所选出站网卡的地址，可能与电视侧的桥接地址不同。先确认路由和实际出站来源，再把这个单独地址加入目标电脑的 RustDesk 入站白名单；保留目标端口、网卡和 Private 网络限制，无需扩大到整个网段。TCP 端口可达仅证明网络通路，不代表认证、图像和键鼠已通过。

## 电视会话

- 短按单击，上下轻扫滚动；停留约 350 毫秒后移动拖拽。静止长按至少 600 毫秒后松开右击；拖拽不会同时触发右键。
- 返回键先释放输入和连接，等原生断开终态后回到列表；面板打开时先关闭面板。没有单独的切换电脑、Esc 或键盘工具按钮。
- 所有控件默认左下角纵向排列，可在设置中统一选择四角和横纵方向；预览展示实际数量与顺序。多个在线显示器时显示切屏按钮，切换期间暂停输入。
- 正常比例时隐藏缩放按钮；超宽屏／竖屏铺满时用减号放大镜缩小为完整画面。只有溢出部分可用摇杆移动。
- 默认 H.265 优先、原画输出、高带宽自适应、60 帧请求。分辨率、码率与帧率独立，提供 30／60／120 帧；高分辨率 VP9 软解最多请求 60 帧并保留压力降帧。实际码率和帧率由电脑、网络及电视共同决定。
- 麦克风打开右侧文字小窗。先选好远端输入位置，再输入或通过系统输入法听写，确认发送；不会自动按回车。小窗打开时暂停远端键鼠，关闭后恢复。
- 实测收起系统键盘后，遥控器语音键会唤起小艺。点“显示键盘”或输入框，确认键盘出现后再长按语音键听写；系统键盘尺寸由电视输入法管理。

## 开机运行

先在终端前台运行并完成端到端测试，再根据 `deployment/` 的样例配置 launchd 或 systemd。替换所有占位路径，不要用管理员账号运行桥接。Mac 的 LaunchAgent 仅在用户登录期间运行；NAS 的 systemd 服务可以独立运行。电脑休眠或网络中断时，电视连接会断开，需要重新连接。

## 常见问题

- 有图像但无法点击：检查电脑辅助功能/输入控制权限，并确认会话不是仅查看模式。
- 黑屏：检查屏幕录制权限、显示器/虚拟显示器状态和编码能力。
- 局域网可用、外网失败：先在桥接设备测试目标端口，再检查 tailnet 访问规则和外网电脑防火墙。
- 语音键唤醒小艺：先点应用文字输入框，确认系统虚拟键盘已出现，再长按语音键。
- 中文输入异常：先在远端普通文本编辑器测试文字面板；物理键盘组合键和各系统输入法行为另行测试。
