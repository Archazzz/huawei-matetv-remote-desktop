# 电视声音基线诊断

更新于 2026-10-25。此文记录已取得的诊断证据与验证边界。本地测试音已通过用户听感确认；Windows 远程音频在提高电视音量后确认可听，但声音偏小；没有实现电脑／电视独占声音切换。

## 已取得的证据

- Windows 端报告：Telegram 使用默认 Realtek Digital Output；输出设备音量 14%、应用会话音量 80%，均未静音。RustDesk 日志选择同名默认输出进行 48 kHz、双声道 F32 回环采集，未发现采集初始化错误。端点 GUID 尚未由日志证实。
- 电视已有日志显示：RustDesk 解码后的 S16LE PCM 非零，播放器提交给系统回调的 PCM 同样非零。输入非零采样中位峰值约 150、RMS 56；输出约 179、RMS 72，输出观察到的最大峰值 448，约 −37.3 dBFS。该统计是间隔抽样，不代表整个音频的最大值。
- Rust Opus 解码代码按样本数将 float 乘以 32767、转为小端 int16；C++ 使用相同的 48 kHz、双声道、S16LE 配置，缓冲区按字节复制。代码审查未发现重复音量缩放或明显的格式错配。
- 音频服务快照中，屏间和华为视频均指向 `DP_speaker`，格式同为 S16LE／双声道／48 kHz。系统策略显示的 HDMI/type27 与此路由对应，单凭该设备名称不能认定输出错误。
- 最近只读快照中，屏间播放器处于 PAUSED；系统与应用音量因子、duck 因子均为 1，未静音。该快照不能说明前一次播放期间的实际声音状态。

Windows 与电视的电平采样并非同一时刻、同一段音频，不能直接相除计算链路衰减。播放器回调收到非零数据也不能证明扬声器已发声。目前没有证据支持安装虚拟声卡或直接放大远程 PCM。

## 本地测试声音

「输入设备测试」右上角新增「测试声音」。仅由用户点击触发，播放 1.5 秒的 440 Hz／660 Hz 混合音，包含 80 ms 渐入渐出，峰值不超过满量程的 0.15。

测试采用 AudioKit 的 MUSIC、48 kHz、双声道、S16LE 播放路径，不依赖电脑、网络或 RustDesk，不修改系统音量，不采集麦克风、不录音。播放期间按钮显示「播放中…」，结束后释放播放器。离开页面会取消；重复点击不创建重叠播放器。

该测试使用 ArkTS AudioRenderer，其系统格式和用途与远程 OHAudio 播放器一致，但并不覆盖原生回调、远程缓冲队列或 Opus 解码实现。因此测试音有声只能建立系统输出可听基线，不能单独证明远程播放路径正常。

## 下一步判定

1. 本地测试音也无声：核查当时系统输出、应用音量与实际播放进度；保持原音量，先排查系统输出路径。
2. 本地测试音有声、远程仍无声：用同一确定有声素材同时读取电脑输出峰值、电视 PCM 电平，以及音频服务读写位置的增长，进一步区分远程输入过低和播放消费异常。
3. 电视远程声音确认可听后，才进行电脑扬声器静音对照，并保存、恢复原设备和音量。现阶段不能承诺扬声器静音后回环采集仍有声。

## 验证状态

本地模拟播放器已检查波形长度、峰值、左右声道一致性、分段／部分写入、重复启动、创建／写入／排空期间取消、写入失败和资源释放。9 项可重复音频测试通过，签名 HAP 已构建并安装。用户实机点击「测试声音」后确认能听到；随后 Windows 远程音频在电视音量提高到 40–50 后也确认可听。低电平来源与端点静音的影响尚待受控对照。

## 语音输入后的系统中断恢复

- 另一次 Mac 会话采样显示系统语音输入强制暂停原生播放器；系统发出 RESUME 提示后，播放器没有注册中断回调，因此持续 PAUSED。此问题与 Windows 低电平不是同一证据链。
- 修复注册独立中断回调，只记录事件；在有效会话的前台控制周期中、未静音且系统明确允许 RESUME 后再启动。回调内不调用 Start 或拿生命周期锁，避免同步重入。STOP 不自动恢复，失败不循环抢焦点。
- 暂停期间的新 PCM 丢弃，恢复时清理旧队列；保留已有暂停实例，防止空闲暂停或格式变化导致重建而绕过系统门控。
- 真实生成的原生处理代码经模拟平台测试，覆盖回调重入、迟到事件、后台／静音门控、空闲交错与失败恢复；签名 HAP 构建通过。实际语音输入后恢复仍需电视验收。

## Windows 端点静音对照

- Windows 端保存并恢复默认 Realtek 输出：scalar 0.14 对应 −29.717651 dB，硬件支持标志为 2（硬件静音），不支持硬件音量控制。scalar 不是线性幅度，不能直接乘应用音量推算录音增益。
- 对照依次为未静音、端点静音、恢复，各约 10 秒。按报告时间对应的电视输入电平各阶段持续非零，播放回调持续推进；静音阶段抽样输入峰值为 7–117，非零样本 10/10。不同视频片段电平不能直接用于计算增益。
- 用户明确确认「书房停了，电视仍有声」。本台 Windows 的当前默认输出路径已通过端点静音独立性测试；恢复复核成功。此结果不能推广到 Mac 或其他输出设备。
- 可据此实现端点状态保存／静音／恢复与电视音频订阅的切换；自动切换按钮和电脑端控制接口尚未交付。当前没有安装虚拟声卡的必要。

## 独立远程音量

- 设置顶部新增「远程声音」0–30 dB 增益，按电脑卡片记忆，默认 0 dB 保持原始字节。只处理当前远程播放器的 PCM，不改变系统音量、本地测试音或其他电视应用。
- 增益上升平滑，立体声联动峰值限幅至满量程的 90%，快速压低突变并逐步释放，避免整数溢出与逐样本硬截断。
- 已通过实际增益、满幅／突变、声道比例、分块一致性、0 dB 恢复、过期会话拒绝及延迟创建保留设置等测试。45 项电视运行时／本地测试音用例通过，签名 HAP 已构建安装；独立增益听感仍待实机验收。
